## NOTES FOR THE NEXT RUN
- Greek slot pairs used so far: (02,05), (03,06), (01,04). Pick an unused pair, for example
  (02,06) or (01,05).
- Story archetypes used: plate in negative space, oversized single word, split screen. Remaining:
  one line low, big centred statement on flat colour, price or number as hero, text only manifesto.
- Story hooks used: use case moment, price point, product spotlight. Remaining: location or
  partner, single provocative line.
- Story language ran EN, GR, EN. Next story should be GR.
- NEVER GUESS A STUDIO FILE FROM ITS NAME. The 2026-08-15 run nearly shipped a Tauro product
  because the STUDIO filenames are all identical prompt fragments. Every candidate must be opened
  and looked at before it goes in a brief. One Tauro frame is hiding in `STUDIO/`; it is listed in
  POOL DEFINITION above.
- Roughly half the remaining pool is the small-product-on-near-black-with-reflection studio look
  (most of `STUDIO/`). Those are weak as references because the product is small in frame. Prefer
  the environmental and editorial frames when there is a choice. The remaining strong environmental
  frames are: atom/editorial botanicals-flatlay, linen-flatlay, smoke, travertine, window-burlap;
  frozen-force burlap-window, smoke, tropical-fruit; souvenir bedsheets, books-candle,
  crackedearth, dashboard-dusk-02, gym, herbs-aloe-flatlay, kraftpaper, rocks-water, smoke-slate,
  tropical, wetsurface, yellowbg. Several of those are warm cream and beige scenes; Section 5 bans
  that palette in the generated imagery too, so the image prompt has to actively regrade them cold,
  as slot 05 did on 2026-08-15.
- SKILLS. `taste-skill` is present in `skills/` but is NOT registered with the Skill tool in this
  sandbox, so it cannot be invoked; read `skills/taste-skill/SKILL.md` directly and run its
  Section 14 Pre-Flight Check by hand. `canvas-design` and `luxury-brand-post-library` do invoke
  normally. `brutalist-skill` and `minimalist-skill` are also read-only SKILL.md files.
- ui-ux-pro-max `search.py` lives at
  `skills/ui-ux-pro-max-skill-main/src/ui-ux-pro-max/scripts/search.py`. Its `--domain color`
  returns shadcn style token sets rather than named palettes, so harvest across several queries and
  take Background / Foreground / Accent hexes. Many returned accents are brass and ochre
  (`#A16207`, `#D97706`, `#CA8A04`) which Section 5 bans; skip those palettes rather than
  substituting a hex.
- ui-ux-pro-max typography rarely returns a Greek capable pairing. Verified Greek capable families:
  Alegreya, Arimo, Comfortaa, Commissioner, Cousine, Fira Sans, Fira Sans Condensed, IBM Plex Sans,
  Inter, JetBrains Mono, Jura, Literata, Manrope, Noto Sans, Roboto Condensed, Roboto Mono,
  Source Serif 4, Syne, Tektur, Tinos, Ubuntu. No Greek: Anton, Archivo, Bebas Neue, Barlow
  Condensed, DM Sans, Epilogue, Figtree, Lexend, Outfit, Playfair Display, Rubik, Sora,
  Space Grotesk, Work Sans. Substitute for the Greek slots and say so in the brief.
- Pillow is not preinstalled in this sandbox. `pip install Pillow` works and is needed for the
  contact sheet.
- `fonts.google.com` and `api.github.com` are blocked by the sandbox proxy. Font TTFs, if ever
  needed again, come from `https://raw.githubusercontent.com/google/fonts/main/<lic>/<slug>/<File>.ttf`.
  Not needed under the new pipeline, since this routine no longer renders type.
